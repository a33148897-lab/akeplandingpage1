Design and build a complete, production-ready React website for AKEP 
(akepacademics.com) — an AI-powered dissertation management platform 
for universities. The website should feel like a premium SaaS product 
(think Notion, Linear, or Vercel in terms of polish), with a dark purple 
brand identity already established.

API INTEGRATION (Render-ready)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

All API calls use:
  const BASE_URL = import.meta.env.VITE_API_BASE_URL

Endpoints to integrate:
  POST /api/waitlist   → { name, email, institution, role, 
                           country, source, challenge }
  POST /api/contact    → { name, email, institution, 
                           subject, message }
  POST /api/newsletter → { email }

All forms:
  - Validated with React Hook Form + Zod
  - Show loading spinner on submit
  - Show success message on 200 response
  - Show error message on failure with retry button
  - Disable submit button during loading
  - Clear form on success
